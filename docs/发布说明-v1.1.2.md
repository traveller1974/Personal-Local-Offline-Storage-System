# 本地库存管理 1.1.2

本补丁处理识别后提示“actualQuantityColumn：必须为布尔值”的问题。

- 服务返回文字形式的 `"true"` 或 `"false"` 时，软件去除首尾空白、忽略大小写，转换后显示兼容提示。全部明细仍须对照原图人工核对。
- 实发列标志缺失、为空，或返回数字、其他文字、数组、对象时，保留可用明细并提示“实发列尚未确认”。即使逐行勾选已核对或填写合计说明，也不能加入进货清单；请包含列标题重新识别，或返回进货清单手动录入。
- 不根据数量、合计或“是”等文字猜测实发列。缺失数量不补零；重复字段、截断 JSON 和无效明细结构继续拒绝，失败保留原有核对明细和草稿。
- 提示词明确要求不带引号的布尔值，无法确认时返回 `false`。软件不会自动重试请求。

安装只更新程序目录，保留已有数据库、照片、Windows 加密密钥设置及备份。安装前请关闭软件；无需管理员权限。本补丁不改变数据库结构，现有三年历史维护规则继续执行。

开发验证使用隔离数据和模拟接口，不读取用户 API Key，不上传用户照片。尚未取得此次失败的真实返回内容；真实云端验收需用户安装后，在软件内主动识别原问题图片完成。
