# 本地库存管理 1.2.1

改进识图时计划数量与实发数量混用的问题。模型逐行输出数量列原文，程序检查其一致性；明确的实发值优先，发生修正或存在矛盾时提示对照，不按差额或合计推算数量。手工修改后仍能按原流程加入清单和确认入库，“已核对”继续作为可选标记。

- DeepSeek 在同一次请求内附带最多8张重叠分段图，帮助辨读较大表格的小字，全部从确认截图中裁出。
- 改进的独立识图 EXE 已嵌入主程序，无需复制模块或另开测试程序。
- 升级保留库存、照片、货品词条、核对记忆、服务选择及加密密钥；图片约40%、结果约60%。
- 两张固定照片完整返回17行和4行，21行数量全部匹配人工基准；仍有编码、颜色和部分类型错误，不能自动提交库存。

关闭主程序后运行 `LocalStockManager-1.2.1-win-x64-Setup.exe`。保存过的DeepSeek设置继续使用；首次使用默认千问。真实测试结果与限制见《验收报告》。更清晰的新照片可作为后续独立测试，当前两张原照片保持为固定基准。
