# 本地库存管理 1.1.4 验收报告

记录日期：2026-10-07（Asia/Shanghai）。本版修复照片进货的人工核对与数量操作，并简化主程序各页面说明。旧版报告保存在 `验证证据/v1.1.3/验收报告-v1.1.3.md`。

## 修复结果

“已核对”可以点击及使用键盘空格。不能核对时逐项说明问题，并滚动、聚焦到需要处理的字段；修改货品或数量后重新核对。顶部显示剩余行数，加入清单时指出未完成的行。

选择已有货品时先显示资料差异，确认后填入类型、名称、规格、颜色和编码。取消时原选择及填写内容保留，照片原文与用户数量始终保留。直接填写完整资料也能查找匹配货品，查询在后台执行，旧结果不会覆盖新输入。精确匹配直接查数据库，不受候选页数量或编码包含匹配影响。

数量单独显示为“本次进货数量”，说明可以点数字输入或点－、＋。加减使用保留绑定的更新方式，真实输入框、核对数据、清单、预览与最终库存保持一致。进货允许0，出货至少1。

单位缺失或不一致时允许明确人工确认数量按库存单位计，原识别代码保留。软件不自动换算数量；人工单位说明与合计纠正说明分别检查，确认单位不能绕过合计差异或实发列缺失。

主程序的货品、进出货、查询汇总、导出、识别设置和备份说明改为直接表达动作和后果。图片40%／结果60%布局保留，原始字段展开可见，技术信息单独折叠。
