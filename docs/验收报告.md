# 本地库存管理 1.1.3 验收报告

记录日期：2026-10-07（Asia/Shanghai）。本版加入名称、规格、颜色词条搜索，并交付启用用户确认可用的识图EXE的升级安装包。所有开发测试使用隔离数据和模拟接口，没有读取用户API Key、上传用户照片或更新真实安装。1.1.2原报告保存在`验证证据/v1.1.2/验收报告-v1.1.2.md`。

## 本版变更与验证结果

名称、完整规格和颜色分别从本机已有货品读取候选，支持包含关键词、去重、完整匹配与前缀优先、空字段展开，以及鼠标和上下键、Enter选择。未选候选时保留原输入，可新建“飞驰”等独立货品名称；颜色可继续留空。读取在后台执行，旧查询和关闭窗口后的迟到结果不会覆盖当前输入。其他字段保留原操作。

手工进货单可直接新建零库存货品，确认后选中并添加到清单。照片核对页选择词条后重新查询完整身份，仍需逐行核对；新建货品窗口中确认的资料会带回当前行，原始识别证据与数量保留。预览和填写不增加库存，只有最终确认入库才增加进货数量。

进货识图弹窗使用约40%图片、60%结果布局，显示全部12个行级字段、实发列状态、原单和当前合计与警告。升级包内置并启用原已确认的单文件识图EXE，复用现有百炼配置，保持原进货流程；原识别实现和离线OCR均保留。

20万行合成流水的组合查询约95毫秒、汇总约87毫秒、完整导出约3.57秒；这些数字只代表本机测试。测试保留了全部20万行，并确认取消不会覆盖已有文件。

原核对保护继续生效：未核对的行、未确认实发列、身份不匹配、无效数量、未解释的合计差异不能加入或提交。字段选择不自动勾选核对。重复行、零数量和原行序继续保存。WPF自动测试使用真实控件与路由事件，没有模拟实体鼠标完整拖动链。

## 数据保护与发布

使用独立注册标识、快捷方式、安装目录及测试数据验证1.1.2→1.1.3安装。安装、重复安装和卸载后，全部14个既有文件的路径与SHA-256一致；真实安装注册保持不变。新版本桌面与识图接入测试使用另一份独立数据，没有触碰基准数据或真实用户数据。

本版不改变数据库结构，仍为v2。安装保存数据，现有三年历史维护在运行时按原规则执行。最终安装包使用LZMA，隔离安装测试使用zlib，二者使用相同发布内容。首次隔离目录因嵌套过深导致Windows无法启动后台子进程，缩短测试目录后全部通过；正式程序使用标准本地缓存目录，识图EXE没有重建或修改。

## 证据与验证边界

当前精简证据保存在`docs/验证证据/v1.1.3`，包括核心和词条专项、发布与安装后的桌面及识图接入结果、升级保留检查、发布指纹和候选列表截图。原1.1.2及更早版本报告与证据保留在历史目录。构建使用锁定依赖，重新打包了本机离线OCR组件，并直接内置被确认的识图EXE。

开发没有调用真实云端，用户反馈不被转换成量化准确率。干净电脑、实体摄像头、不同Windows用户的DPAPI及长时间人工交互尚未测试。布局使用WPF变换模拟100%／125%／150%缩放，实际显示器DPI切换仍需在使用中核对。

本次仅交付本地安装包与源码、报告，未发布远程版本，未运行实际用户安装更新。
