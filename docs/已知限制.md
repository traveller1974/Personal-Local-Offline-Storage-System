# 1.3.0 已知限制

- 本次1.3.0界面改版使用本地回放，没有新增真实模型调用；以下准确率为1.2.1及历史测试结果。
- 长规格会增加行高，需要纵向滚动；较窄窗口需要横向滚动。当前显示器144 DPI渲染已检查，其他缩放使用布局模拟，不能代表所有实体显示器或多显示器环境。

- 千问真实样单未通过自动填单验收：17行样单新旧版本均只返回8行；4行样单新版返回内容无法解析，旧版只返回3行。存在漏行、数量和货品字段错误。请对照照片检查，不能把“接口调用成功”当成识别正确。
- DeepSeek 已使用用户提供的同两张照片真实调用6次。最终版本完整返回17/4行且21行数量均匹配人工基准，仍有编码、颜色和两行类型错误，未通过全自动填单验收。首次使用默认千问；升级保留已有DeepSeek选择和密钥。固定基准不要求换照片，清晰的新照片可单独检验。
- “已核对”为可选标记。识别数量列不明、照片单位缺失、照片合计不同均不限制有效的手工填写。有效货品、整数数量和库存范围仍必须满足；入库使用最终清单。
- 软件不会自动提交库存。识别可能漏行或多行，可在同一窗口补充、移除和修改，然后检查最终确认页。
- 核对记录帮助匹配已有货品，不会训练云模型，也不保证每次识别更准确。第一次确认的关联仅作候选；同一样式在两张不同有效货单中确认且无冲突后，才允许自动匹配。数量永远不从旧货单带入。
- 可以关闭记忆或停用错误记录。记录来自已入库单据；取消填写、失败入库不学习。已作废或清理的单据、停用或已修改资料的货品不参与记忆匹配。
- 人工基准共两张货单21行，其中39个完整名称、规格或颜色字段仍待确认，不计为正确，不使用模型答案补作标准。当前样本量不足以证明通用自动填单效果。
- 主识别没有可信行坐标或置信度。千问文字定位需额外请求；重复文字不自动绑定行。DeepSeek 暂无该定位功能。
- DeepSeek 对较大的表格和长截图会同时发送整图和最多8张重叠细节图；可能增加输入用量。当前两张照片分别使用4/2张分段图，没有漏行或多行，但极长货单的交界处理仍需真实验证。
- 数量候选属于模型提取结果，也可能有错。仅在列已确认且唯一实发值有效、已读出的三列关系没有矛盾时采用该值；修正会提示对照。矛盾不通过减法、合计或旧单据补数，手工修改仍有效。
- 表格检测只给出候选。请在本机裁剪并确认上传范围。模型请求使用确认后的截图；启用核对参考后，最多3条相关货品修正也可能发送到所选服务。
- 默认一次请求。有相关核对参考且缺失字段时，主程序最多再补充一次，合计等待预算180秒。鉴权、余额、网络失败不自动重试、不自动切换模型。取消后服务端仍可能已处理并计费。
- 本机离线备用识别适合简单表格，对复杂分区货单没有精度承诺。原单位不明确时需要人工核对、必要时自行换算，软件不按单位代码自动换算。
- 旧版货品缺失的类型、颜色或编码不自动推测；需手动补全。新建零库存货品后取消进货，仍保留档案，但不增加库存。
- 名称、规格、颜色词条来自本机已有资料，包含停用货品用过的文字，最多50个候选；选择词条只填当前字段，不自动创建或选择整个货品。
- 升级验证使用独立目录、注册表和数据。真实用户软件需关闭后自行运行安装包；干净电脑、跨Windows用户的密钥解密、实体摄像头和长时间使用未覆盖。密钥不包含在库存备份中，换电脑需重新配置。
- 各电脑独立保存数据，无账户同步、多人协同或多仓库。20万行性能结果来自本机合成数据，不代表所有机器。
- 三年维护不删除另存的保护备份和Excel。纠错数据库也可能保留旧文字，但来源单据已清理的记录不再参与匹配；长期归档由用户管理。
