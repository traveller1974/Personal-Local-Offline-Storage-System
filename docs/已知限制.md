# 1.1.0 已知限制与验证边界

- 未配置百炼密钥，未上传两张真实样单。真实识别准确率、真实请求耗时、Token 用量、付费金额和地域模型权限尚待验证；模拟接口通过不代表真实云端样单验收通过。
- 两张样单的原行序、类型、实发数量、原单位、标识和可辨编码已有人工照片基准；模糊的完整名称、规格或颜色标为空待确认，不把模型输出当作标准答案。
- 主识别不提供可信行坐标或置信度；文字定位是额外请求，重复文字不会自动绑定行。
- 自动表格候选可能包含其他区域。必须在本机调整四角或裁剪，并确认表外客户资料和二维码已经排除。
- 网络取消会停止等待，但服务端可能已经处理请求并计费，主动重试可能再产生费用。没有自动重试。
- 本机离线备用识别保留旧文字与表头解析能力，对这些复杂分区货单的精度没有承诺；需要人工核对或手工录入。
- 旧版缺失的类型、颜色和物料编码不自动推测，不自动拆分既有库存；需要人工补全。历史缺失字段仍显示“未记录”。
- 新建零库存货品后取消进货草稿，会保留零库存档案；不会产生进货库存增量。
- 性能数据来自本机合成20万行流水，不代表所有机器、相机和真实云端服务的表现。硬件、数据规模和实测数值见验收报告。
- 升级和卸载使用独立测试注册表、快捷方式和目录验证，未改动当前真实安装；干净电脑、不同 Windows 用户的 DPAPI、实体摄像头和人工交互长时间使用尚未验证。
- 独立电脑分别保存数据，无账户同步、无多人协同、无多仓库；Excel 为文本与数字输出，不支持以自选字段排序或自定义公式。
- 三年维护不会自动删除用户保存的保护备份或导出文件。它们可能保留旧历史，长期归档由用户管理。
