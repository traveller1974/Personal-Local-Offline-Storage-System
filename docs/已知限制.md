# 1.0.0 已知限制与验证边界

- 支持 Windows 11 x64（Intel / AMD）；Windows 11 没有32位版本，本版不面向 Windows on ARM。
- 已验证通用中文打印货单、轻微倾斜图片、多个数量列与中文含空格路径。尚无用户实际厂家的货单样本，尚未验证其识别准确率。多行合并单元格、手写、严重反光或模糊图片可能需要人工修正或手动录入。
- 识别结果始终需要逐行人工核对和最终入库确认。无法识别表头时，软件会提示手动录入或换照片。
- 摄像头入口与原生依赖已实现；开发机未完成有实体摄像头的拍摄验收，硬件与权限差异仍需验证。
- 已在开发机 Windows 11 x64 测试自包含应用及实际安装链路。没有可用的干净 Windows 11 虚拟机，A23 的“断网、无 Python/.NET SDK/Office 的干净电脑”验收未验证，不能用开发机结果代替。
- 安装包未签名，Windows 可能显示未知发布者或 SmartScreen 提示。
- 首版不包含价格、利润、金额业务、退货、报损、盘点修改总数、多用户权限、手机应用或联网同步。单台电脑不能同时运行两个库存实例。
- 备份中的旧记录恢复后仍按最近五年清理；请保管导出的 Excel 或历史备份以备长期归档。
