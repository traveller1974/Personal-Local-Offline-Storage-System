## 验证覆盖

独立单元测试保留原模块的响应结构和解析兼容规则，覆盖缺字段、完整规格、重复行、零数量、异常数量、未知类型、布尔字符串、额外字段、重复键、截断、官方端点校验、鉴权与余额错误、限流、超时、取消和定位坐标。诊断与评估覆盖原始响应保存、密钥和图片编码过滤、模型值与解析值分别比较、模糊人工字段不计正确、无效数量与未知类型不能生成假合计。

独立单文件检查使用合成图片和模拟响应，验证裁剪预览不改动上传字节、缩放坐标、旋转与恢复、全部字段、四个分区合计、原始与解析内容分别展示、准确截图导出、失败结果可导出、忙碌状态防止重复请求及取消后丢弃迟到响应。EXE 后台入口通过实际子进程测试 UTF-8 管道、请求编号和协议版本、完整结果和定位坐标、错误返回、超时停止和取消杀进程；不会弹出独立测试窗口，密钥不在进程参数、输出或 stderr 中。

主程序接入验证覆盖内置资源、哈希缓存、损坏缓存修复、全部类型与12个字段映射、耗时和 Token 保留。仅在本地提取失败且未开始调用时使用原实现；新模块返回错误后没有自动向原实现重发请求。默认开关和启用开关均通过实际发布配置验证。

原进货流程已完整验证：后台返回明细 → 精确关联货品 → 每行人工核对 → 加入进货清单 → 预览 → 确认入库。重复货品保持独立原行，零数量仍保留，原序号和标识随单保存；未核对和未确认实发列不能加入，加入草稿之前库存不变，确认后库存合计正确。既有裁剪预览、兼容字段处理与入库保护回归也继续通过。

布局覆盖默认1360×900、最小1040×680及1600×1000；以 WPF 布局变换模拟100%／125%／150%，窗口同步放大以保持对应逻辑尺寸。两个页面均维持约40%／60%，长字段换行且没有横向截断。实际显示器 DPI 切换和长时间人工操作仍需使用中核对。
