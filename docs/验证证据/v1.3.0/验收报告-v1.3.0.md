# 本地库存管理 1.3.0 验收报告

记录日期：2026-10-07。主程序、业务弹窗和独立识图工具的界面改版及隔离升级验证通过。本次没有新增真实模型调用。历史完整识别验收保存在 `验证证据/v1.2.1/验收报告-v1.2.1.md`。

## 界面交付

统一采用柔和蓝灰配色、圆角按钮、矢量图标和清晰的悬停、按下、禁用、键盘焦点状态。常用正文及提示颜色的对比度达到4.5:1；长时间使用的舒适程度仍需实际使用反馈。

库存表默认名称1份宽度且最多180，规格3份且至少240，颜色1.5份且至少140；类型72、单位56、编码110、操作152。以上为WPF逻辑像素。名称、规格、颜色和编码完整换行，行高随内容增加，不用省略号隐藏文字。数量保持整段显示，位数较多时自动加宽。可拖动列宽；窄窗口用横向滚动，超长行用纵向滚动，放大窗口时规格获得更多空间。行虚拟化保留。

进出货清单、货品选择、汇总、确认页和单据详情同步改善长文本展示。调整库存分布窗口保留名称、规格、类型、颜色、编码和单位供核对，底部操作保持可用。设置页按照片识别、核对记录和本机备份分组，正文可滚动，关闭按钮固定在底部。窗口初始大小适配当前显示器工作区，底部版本号与实际构建一致。

原进货步骤、名称/规格/颜色词条和约40%图片/60%结果布局保留。“已核对”继续为可选标记；数量列不明、单位缺失或照片合计不同仅提供提示，不否决有效手工填写。加入清单不改变库存，最终确认才入库。改版后的同一独立EXE已嵌入主程序，无需用户手动复制模块。
