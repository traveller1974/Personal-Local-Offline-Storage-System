# 本地库存管理 1.1.3

发布日期：2026-10-07。

本版增加进货填单的名称、规格和颜色词条搜索，并将用户确认可用的独立千问识图EXE嵌入升级包。安装后继续按“进货 → 照片识别 → 核对 → 加入清单 → 确认入库”操作，复用已保存的百炼配置。

- 三个字段输入关键词后显示已有词条，鼠标或上下键、Enter选择填入；不选候选时保留输入，可新建“飞驰”等独立名称。颜色为空时可查看已有颜色，也可留空。
- 词条分别取自现有货品的名称、完整规格和颜色，去重、优先显示完整匹配和前缀匹配，最多50项。匹配包含关键词，不将百分号或下划线解释为通配符。读取在后台执行，快速输入、关闭窗口时取消旧结果。没有新增其他字段的词条功能。
- 手工进货单提供“新建货品”入口，确认后选择零库存档案；加入清单和最终确认入库沿用原规则。
- 识图弹窗图片约40%、结果约60%，显示全部12个行级字段、原单与当前分区合计、实发列状态和警告，长字段换行、可纵向滚动。
- 新后台内置的是原已确认EXE，SHA-256为`59f55f710918b1e54a275f4e204118e6881e96c16df33aa255b3db5d04d72700`；不重新生成模型调用模块。原识别实现和本机离线备用识别继续包含在主程序中。

安装前关闭软件，再运行`LocalStockManager-1.1.3-win-x64-Setup.exe`。安装包仅更新程序，数据库结构仍为v2，已有库存、照片、加密配置和备份保留。无需单独启动识图EXE。新建零库存档案后取消草稿仍会保留该档案，库存不增加。

144项核心测试、105项发布及安装后桌面检查、122项发布及安装后内置识图检查、12项升级／重复安装／卸载检查均通过。14个测试数据和配置文件逐项哈希一致，实际安装注册未改变。验证使用隔离数据库、合成图片与模拟服务响应，没有读取用户密钥或调用真实模型；用户已反馈识图模块可用，开发验证不提供真实准确率统计。结果见本版验收报告与`docs/验证证据/v1.1.3`。
