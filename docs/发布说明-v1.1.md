# 本地库存管理 1.1.0

新增百炼 `qwen3.5-ocr` 识别、表格四角及透视校正、逐行核对，按类型、名称、完整规格、颜色和物料编码区分库存，支持组合筛选、汇总和全结果 Excel 导出。

安装前关闭软件，运行 `LocalStockManager-1.1.0-win-x64-Setup.exe` 即可升级。安装只更新程序文件，现有数据库、照片、密钥设置和备份保持原样。首次启动会先创建完整保护备份，再迁移旧数据库；库存余额及历史快照不改写。软件继续执行原计划的三年历史保留规则，首次缩短保留年限前另存完整保护备份。卸载也保留数据。

验证结果：核心回归 70 项、WPF 集成 36 项、隔离安装升级及卸载 11 项通过；安装和卸载前后逐文件 SHA-256 保持一致。20 万行完整 Excel 导出约 3.5 秒，支持取消。源码附精简验证证据，文档压缩包附说明、报告和截图。
