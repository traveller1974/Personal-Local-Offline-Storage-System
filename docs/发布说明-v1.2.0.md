# 本地库存管理 1.2.0

修复识图结果人工填写后仍因“实发列尚未确认”无法加入清单的问题。数量列、照片合计和照片单位的识别疑问现在作为提示显示，入库采用最终填写值。“已核对”作为可选检查标记，修改数量后无需反复勾选。

- 自动匹配完整、唯一的已有货品；名称、规格、颜色继续支持关键词词条。
- 识图页可补充漏行、移除多余行，并保留原始结果供展开对照。图片40%，填写区域60%。
- 成功入库后记住人工修正，相关修正可作为以后填写的参考。两张不同有效货单确认同一关联后，才允许记忆自动匹配。
- 新增 DeepSeek 官方识别服务选项，默认保留千问。两个服务的密钥由 Windows 分别加密保存。
- 独立识图 EXE 新增模型选择、对比和核对参考开关，测试通过的同一文件嵌入升级包。
- 备份包含本机核对记录，旧备份可继续恢复。升级保留已有库存、照片和设置。

使用方式：关闭主程序，运行 `LocalStockManager-1.2.0-win-x64-Setup.exe`，再按原来的“照片识别进货”步骤操作。识别后检查提示的内容，加入进货清单，最后确认入库。数量可以在两个页面继续修改。

设置中可以选择千问或 DeepSeek、关闭记忆、停用错误记录或补记已入库的修正。独立测试程序不会自行更新库存；需要试另一模型时先在独立程序测试，再在主程序设置中选择并保存对应服务。

识别准确度的范围及真实样单结果见本版验收报告。未完成真实验收的场景请继续对照照片检查；程序没有自动提交库存功能。
