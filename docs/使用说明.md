# 本地库存管理 1.0.0 使用说明

适用于 Windows 11 x64（Intel / AMD）。双击 `LocalStockManager-1.0.0-win-x64-Setup.exe`，按向导安装。无需管理员权限，也无需安装 Python、.NET、数据库或 Office。所有功能在本机运行，首次识别也不需要联网。

## 首次录入库存

打开软件即进入库存首页。点击“新增货品”，填写名称、规格和单位，分别录入仓库与店面期初数量；查看预览后确认。货品按“名称＋规格”区分，单位建档后固定。期初库存不算厂家进货。所有数量只接受整数，数量框左右按钮每次减1或加1。合计始终等于店面加仓库。

## 手动进货和出货

进货页选择“手动进货”，渠道固定为厂家。出货页选择“新增出货单”，必须选择零售或批发。选择货品、填写数量，再“添加到清单”。重复添加同一种货品会合并数量；删除明细请点击“移除”。

点击“查看确认页”，核对每项货品、规格、数量及仓库、店面、合计变化，再点击“确认入库”或“确认出库”。最终确认前取消、返回编辑或关闭窗口均不会改变库存。成功后显示单据编号。保存失败时保留清单，可核对错误提示后重试。

进货和出货都只在仓库记账。店面有库存但仓库不足时不能出货，需先调整分布。

## 照片识别进货

先把手机拍摄的货单照片复制到电脑。在进货页点击“照片识别进货”，选择或拖入 JPG / PNG 文件，也可点击“摄像头拍照”。若没有摄像头或权限被拒绝，仍可选择照片。

拍照时让打印表格清晰、平整，避免反光和遮挡。可向左或向右旋转、缩放查看；点击“框选裁剪”后在左侧照片中拖框，松开完成裁剪。“恢复原图”可重新处理。

点击“识别当前照片”，右侧显示可编辑明细。多个数量列存在时，请明确选择数量或实收数量列。单价、金额和合计不会默认当作入库明细。

逐行核对名称、规格和数量；“定位照片”可显示该行的图片位置。准确匹配已有货品时会自动关联；其他情况请手动选择货品，或点击“新建货品”创建期初为0的档案。未知货品不能重复建档；停用货品需先回到库存首页重新启用。低置信度或无效数量会显示提示。

每行勾选“已核对此行”后，才能点击“加入进货清单”。编辑已核对的数量或货品会清除核对状态。加入清单仍不会增加库存；随后须查看确认页并最终确认入库。可以再次打开照片窗口，把多张货单汇集到同一进货单。成功记账时保存原图和处理图副本，用户原照片不会被软件删除。

识别可取消，120秒超时会停止。识别失败时可裁剪后重试、换照片，或关闭窗口手动录入。通用识别无法保证每张货单完全准确，请始终人工核对。

## 调整店面与仓库分布

在库存首页的货品行点击“调整分布”，选择仓库→店面或店面→仓库，输入数量并确认。来源库存必须足够。调拨只改变两处数量，不改变货品合计，也不算进货或销售。

## 作废错单

在记录查询中打开进货或出货单，点击“作废此单据”，填写原因、核对反向库存变化，再确认作废。原单保留为已作废，当前日期产生反向流水。任何一项会导致负库存或超过上限时，整单作废会被拒绝。不能重复作废。期初与调拨不能作废，调拨错误请用反方向调拨纠正；错单作废后可重新录入正确单据。

## 查询和导出 Excel

支持今日、昨日、过去7天、上个月、过去3个月、过去6个月、去年和自选日期。开始与结束当天都包含。可筛选类型、渠道、货品名称或规格、有效或已作废状态。

默认显示进出货记录；勾选“库存变动记录”可查询期初、调拨和作废反向流水。每页100张单据。“导出 Excel”应用当前筛选条件并导出全部命中明细，不受分页限制。

Excel 含明细、汇总和筛选说明。汇总只计入当前有效的进出货原单，作废原单及反向流水不计入进货或销售。单据明细保留建单时的货品名称、规格与单位。

## 五年保留、备份和恢复

软件启动、运行跨日和恢复备份时，自动删除五年前的流水与失去引用的货单副本。删除前结转旧流水，两处当前库存保持不变。查询范围包含已删除日期时会提示，仅保留最近5年记录。软件关闭时不运行后台清理，下次启动补做。货品档案、当前余额、用户保存的 Excel 与备份不受自动删除影响。

在“设置与备份”点击“保存备份”，另存 `.stockbackup` 文件；备份包含一致的数据库快照与照片。建议定期保存到外置硬盘。

恢复会替换本机全部数据，请先保存需要的当前备份，再选择“恢复备份”。软件先在临时目录检查文件校验、数据库版本、库存一致性和照片，再切换数据。无效备份被拒绝；有效备份恢复后也会按当前日期执行五年清理。不能合并多个备份。

程序默认位于 `%LOCALAPPDATA%\Programs\LocalStockManager`，数据位于 `%LOCALAPPDATA%\LocalStockManager\Data`。每台电脑的数据独立；升级保留数据，卸载默认保留数据。无需登录，不进行联网同步。
