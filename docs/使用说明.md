# 本地库存管理 1.1.0 使用说明

适用于 Windows 11 x64（Intel / AMD）。双击 `LocalStockManager-1.1.0-win-x64-Setup.exe` 安装，旧版用户先关闭软件后升级。无需管理员权限，也无需安装 .NET、Python、数据库或 Office。

## 第一次升级和货品资料

库存与照片保存在 `%LOCALAPPDATA%\LocalStockManager\Data`。升级不会替换这个目录。v1 数据库升级前会创建完整保护备份，事务迁移到 v2；首次三年清理前再创建完整保护备份。备份位于数据目录旁的 `ProtectionBackups`，其中可能包含旧历史，不会自动清理。

旧货品显示“待补全”，颜色和编码显示“未记录”。旧货品仍可手工进出货、调拨，但不能由云端识别自动关联。点击“编辑”，选择货物类型，补全名称、完整规格、颜色、物料编码，勾选“明确补全 / 纠正”，再保存。完整身份冲突会阻止保存，不会自动合并或拆分库存。历史单据仍显示当时快照，不把补全资料写回旧行。

类型与单位固定对应：成车为“辆”，电池为“组”，充电器为“个”，附件为“件”。电池和充电器颜色必须留空。物料编码不存在时，可在人工核对后留空；空编码只匹配另一个空编码，不匹配其他编码。同编码不同规格或颜色分别建档。标识 X1、A 等随单据明细保存，不区分库存。

## 配置百炼联网识别

在“设置与备份”中填写阿里云百炼 API Key、控制台提供的地域原生服务地址，以及控制台要求的业务空间标识。模型固定为 `qwen3.5-ocr`。密钥与地域必须匹配；部分业务空间需使用形如 `https://业务空间.cn-beijing.maas.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation` 的地址，请以自己的控制台为准。

API Key 由 Windows 当前用户加密，保存在数据目录旁的 `Settings/qwen.dpapi`，不进入库存备份。换电脑或 Windows 用户时需要重新配置。默认直连服务，不修改系统代理。识别按输入与输出 Token 计费，软件不推算或承诺单次费用。

## 照片进货

1. 在“进货”点击“照片识别进货”，选择、拖入 JPG/PNG，或摄像头拍照。
2. 程序在本机检测表格，橙色四边形仅作为候选。点击“调整四角”，依次点击左上、右上、右下、左下，然后“应用四角”做透视校正；也可“框选裁剪”。旋转后检查范围。
3. 截图须保留表头、全部货品行和分区合计，并排除客户资料、二维码、物流备注。对照截图后勾选允许上传。只有点击“识别确认的截图”才会上传。
4. 逐行核对名称、完整规格、颜色、实发数量、系统单位、标识、类型和编码。数量只取实发，零实发仍保留单据行。PC 需结合分区区分成车和充电器。
5. 完整身份一致时会显示关联货品，但不会自动标记已核对。可搜索关联货品或新建零库存货品；新建货品不把照片数量计入库存。新建档案即使取消草稿仍保留零库存档案。
6. 每行必须勾选已核对。编辑字段、关联货品会撤销核对；分区合计不一致时先修正，或明确核对原单合计有误并填写原因。没有实发列不能加入清单。
7. 点击“加入进货清单”后可再导入下一张照片。保持照片顺序和原行序，重复货品独立成行。同一草稿不允许重复截图；历史使用过的截图会提示重复风险。
8. 核对草稿，再查看确认页并最终确认入库。只有最终确认才增加仓库库存。草稿修改照片数量会撤销核对，并重新检查分区合计。取消不会记账。

主识别不会显示推测的坐标或置信度。默认用截图缩放对照。“文字定位”会经确认另发一次付费请求，同一图片会话内复用结果。只有完整文字唯一匹配才高亮；重复文字仅列出候选，不绑定某一行。

鉴权、欠费、权限、限流、连接失败、超时和截断会分别提示，图片和已有草稿保留，没有自动重试。等待上限90秒，可取消；迟到响应不会覆盖明细。断网可选择本机离线备用识别或手工录入；离线识别仍须检查数量列和所有字段。

## 手工业务、调拨与作废

新增货品的期初库存单独记账，不计入厂家进货。厂家进货增加仓库库存；零售或批发出货只扣仓库，必须明确渠道。仓库不足时先“调整分布”，从店面调回仓库；调拨不改变合计。库存不允许负数。

库存、进出货选品可搜索名称、规格和编码，也可组合筛选；选品每页100种。进出货中的相同货品可以有多行，确认页按货品合计显示库存变化。

记录详情显示全部原行、照片序号、原序号、标识和字段快照。作废须填写原因，在当前日期生成反向流水；重复行按货品合计校验余额，不会重复扣减。不能作废已作废单据。

## 查询、汇总与导出

“组合筛选”支持类型、名称、规格、颜色多选，以及物料编码搜索。同字段多个选项为“或”，不同字段为“且”。规格与颜色候选来自实际货品，可搜索和翻页。空颜色显示“无颜色”；旧资料的“颜色未记录”另选。

记录查询每页100张单据，只显示符合筛选的明细；打开单据详情仍保留完整原单。日期选项包括今日、昨日、过去7天、上个月、过去3个月、过去6个月、去年及自选。

“汇总 / 展开”可组合名称、规格、颜色维度，类型与单位始终分开。库存显示仓库、店面和合计；进出货只计有效原单，作废原单与反向流水不会重复计入。双击汇总行查看分页明细。

库存与记录均可导出 Excel。选择明细列和汇总维度，身份字段默认勾选；可只导出汇总。导出覆盖全部结果，附筛选条件、维度、时间及保留起始日。大量数据按工作表上限分表，导出过程中窗口可响应、可取消；取消或失败不会覆盖既有目标文件。

## 三年保留与备份恢复

保留截止日为本机业务日期减三年，截止日当天保留。启动、跨日和恢复时先结转过期流水，核对“结转＋保留流水＝当前余额”，再清理过期单据与无引用照片。非零库存以及仍被保留单据引用的货品不删除；无库存、无引用且三年未使用的货品才会删除。旧货品使用时间不明时从迁移日保守计算。

时钟回拨不会重新开放已清理日期；照片删除失败记日志、下次重试。用户另存的备份与 Excel 不自动删除，备份可能仍包含三年前历史。

在设置中保存 `.stockbackup`，包含数据库和关联照片，不包含 API Key。恢复前先备份当前数据；恢复支持 v1/v2，先在暂存目录校验、迁移、核对并执行三年维护，成功后才替换当前数据。不能合并多个备份。卸载保留库存、照片、密钥设置和保护备份。
