# 本地库存管理 1.2.1 使用说明

适用于Windows 11 x64（Intel / AMD）。先关闭主程序，再运行 `LocalStockManager-1.2.1-win-x64-Setup.exe`。无需管理员权限、.NET、Python或Office。升级保留库存、照片、设置和备份，使用流程不变。

## 货品资料

库存保存在 `%LOCALAPPDATA%\LocalStockManager\Data`，设置与保护备份位于旁边。v1升级、首次三年维护前先创建保护备份，再事务迁移。1.2.1库存数据库仍为v2。

旧资料显示“待补全”时，编辑类型、名称、完整规格、颜色和编码，并确认保存。旧货品可继续手工使用，但云端不会自动关联资料不完整的档案。历史单据保留当时快照。

成车单位“辆”、电池“组”、充电器“个”、附件“件”。电池和充电器颜色留空；不存在的编码可人工确认后留空。同编码不同规格或颜色分别建档。X1、A等标记随单记录，不区分库存。

## 设置识别服务

在“设置与备份”中选择千问或DeepSeek，填写该服务的API Key和地址，再点“保存识别设置”。两个服务的密钥分别加密保存，切换服务不会覆盖另一份。

- 千问：模型 `qwen3.5-ocr`，使用百炼原生DashScope地址；密钥地域、业务空间与地址须按控制台填写。
- DeepSeek：模型 `deepseek-flash`，官方地址 `https://api.deepseek.com/chat/completions`，无需百炼业务空间。旧的实验模型别名已停用，本版使用当前官方型号。

密钥由当前Windows用户加密保存在 `Settings`，不进库存备份。换电脑或Windows用户时重新配置，请勿把密钥发到聊天或写入源码。识别直接连接官方服务，不更改系统代理，按服务计费。

首次使用默认千问；升级保留已经保存的服务选择和密钥。两张固定照片的 DeepSeek 测试已完成，改进版完整返回21行且数量全部匹配人工基准，但编码、颜色和部分类型仍有错误，未通过全自动填单验收。请继续对照照片，最终由用户确认入库。

## 照片进货

1. 在“进货”点击“照片识别进货”，选择、拖入JPG/PNG，或摄像头拍照。
2. 检查橙色表格候选；需要时“调整四角”，依次点击左上、右上、右下、左下并应用，或“框选裁剪”后预览、应用。取消预览保留当前填写。应用裁剪或旋转后，重新确认截图范围。
3. 保留表头、全部货品和合计，排除表外客户资料、二维码和物流备注；检查截图后勾选允许上传，再点击识别。
4. 图片约40%、填写区域约60%。唯一匹配的已有货品可自动填资料，其余行选择已有货品或新建。名称、规格、颜色输入关键词可选择词条，也能保留新值。
5. 在绿色区域修改“本次进货数量”，点数字直接输入，或点－、＋。进货允许0，只能填整数。照片识别的数量只供对照，入库采用最终清单的值。
6. 单位或数量列没有看清时，对照照片填写；需要换算时自行把数量改为库存单位。照片合计不同也可继续填写，“数量说明”可留空。这些识别提示不会限制加入清单。
7. 可点击“已核对”或用空格标记检查过的行，也可不勾选。修改数量不需要重复勾选。有无效数量、未选择货品或资料冲突时，页面指出需要处理的字段。
8. 漏行点“补充一行”，多余行点“移除此行”。原始字段可展开“照片识别原文”对照；“查看未填完整的行”跳到需要补齐的位置。
9. 点“加入进货清单”。可以再导入下一张照片，重复货品保留独立行。同一草稿不能重复加入相同截图。加入清单不会改变库存。
10. 在清单继续修改数量，点击“查看确认页”，核实后“确认入库”。只有最后确认才增加库存；记忆也在这一步成功后保存。

有效货品和整数数量仍由业务规则检查；识别错误不会越过这些检查。没有“实发列已确认”标志时也可以在当前窗口填写并加入，不必退出重新手工录入。

识别已找到实发列时，程序核查每行数量与该列读出的值是否一致；可辨明的实发值优先，并提示发生过的修正。计划、实发、欠发三列互相矛盾时提示检查，不用计划数减欠发数或按合计凑数量。你仍可直接修改并加入清单。

默认一次请求，有相关核对参考且仍缺失字段时最多补充一次，总等待预算180秒，单次服务请求90秒；可取消。网络、鉴权或余额失败不自动重试、不自动切换模型。已有填写保留，迟到响应不覆盖人工修改。断网可主动选“本机识别”或手工填单。

DeepSeek 对较大的表格和长图，在同一请求中附上最多8张重叠分段图帮助看清小字，分段只来自你确认的截图。可能增加用量；无需额外操作。分段不能保证消除识别错误。

千问“在照片中查找”另发一次需确认的付费定位请求；完整文字唯一匹配才高亮，重复文字不绑定行。DeepSeek 暂不支持定位，用左侧缩放对照即可。

独立识图程序已嵌入升级包，在后台运行；无需启动测试窗口或复制EXE。真实准确度未通过的场景仍需对照照片检查。

## 记住核对修改

“设置与备份”中可开关“记住核对修改”、查看记录、停用错误记录、补记已入库的修正或导出核对参考。关闭后不使用历史修正、不学习新修正，已有货品匹配和手工填写仍可用。

成功入库后保存原始识别与最终表单。第一次人工确认的货品关联只作候选，同一样式在两张不同有效货单中确认且无冲突后才自动匹配。仅改数量不把自动货品关联算成人工标准，旧数量绝不用于下一张单据。作废单据、停用或已改资料的货品不再参与匹配。

参考不是训练云模型。启用后，最多3条相关货品修正可能随截图发送给所选服务。独立程序可载入导出的参考，验收新单据时关闭参考以检查实际效果。

## 手工填写、出货和作废

名称、规格、颜色可选择已有词条或直接填新值。输入“飞驰”可选择“飞驰一代”“飞驰二代”，也可保留“飞驰”新建。颜色留空时点击字段或下拉箭头可选“薄荷绿”“天蓝”。上下键选择、Enter填入、Esc关闭、Tab跳转。最多50条候选，更多结果用关键词缩小范围。选择词条只改变当前字段。

手工进货可以新建零库存档案再加入清单；取消草稿仍保留档案，但不增加库存。期初库存单独记账，不计入厂家进货。出货须选择零售或批发，只扣仓库；不足时先从店面调回仓库。调拨不改变合计，不允许负库存。

库存和选品可搜索名称、规格、编码，每页100种。确认页按货品合计显示变化。记录详情保留全部原行、照片序号、原序号、标记和快照。作废填写原因，以当前日期生成反向流水；重复货品合计校验，已作废单据不能再作废。

## 查询和导出

“组合筛选”支持类型、名称、规格、颜色多选及编码搜索。同栏匹配任一选项，不同栏条件同时满足。空颜色和旧资料“未记录”分别选择。

记录每页100张，只显示符合筛选的明细；详情保留完整原单。可选常用日期或自定范围。“分类汇总”按选定名称、规格、颜色汇总，类型与单位始终分开；作废原单与反向流水不重复计入有效进出货。

Excel覆盖全部筛选结果，附条件、时间和维度。大量数据分工作表；导出可取消，失败或取消不覆盖已有文件。

## 备份和三年维护

设置中保存 `.stockbackup`，包含库存数据库、关联照片和本机核对记录，不包含API Key。旧备份没有核对数据库仍可恢复。恢复前先备份当前数据，再在暂存目录校验、迁移和维护，成功才替换；不能合并备份。卸载保留数据和设置。

启动、跨日和恢复时按本机日期保留三年记录，先结转并核对余额，再清理过期流水和无引用照片。有库存或仍被引用的货品不删除。时钟回拨不重新开放已清理日期。另存的备份、导出文件不自动删除，长期归档由用户管理。
