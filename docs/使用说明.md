# 本地库存管理 1.1.4 使用说明

适用于 Windows 11 x64（Intel / AMD）。双击 `LocalStockManager-1.1.4-win-x64-Setup.exe` 安装，旧版用户先关闭软件后升级。无需管理员权限，也无需安装 .NET、Python、数据库或 Office。

## 第一次升级和货品资料

库存与照片保存在 `%LOCALAPPDATA%\LocalStockManager\Data`。升级不会替换这个目录。v1 数据库升级前会创建完整保护备份，事务迁移到 v2；首次三年清理前再创建完整保护备份。备份位于数据目录旁的 `ProtectionBackups`，其中可能包含旧历史，不会自动清理。

旧货品显示“待补全”，颜色和编码显示“未记录”。旧货品仍可手工进出货、调拨，但不能由云端识别自动关联。点击“编辑”，选择货物类型，补全名称、完整规格、颜色、物料编码，勾选“我已核实本次修改的货品资料”，再保存。已有货品的资料相同时会阻止保存，不会自动合并或拆分库存。历史单据仍显示当时快照，不把补全资料写回旧行。

类型与单位固定对应：成车为“辆”，电池为“组”，充电器为“个”，附件为“件”。电池和充电器颜色必须留空。物料编码不存在时，可在人工核对后留空；空编码只匹配另一个空编码，不匹配其他编码。同编码不同规格或颜色分别建档。标识 X1、A 等随单据明细保存，不区分库存。

## 配置百炼联网识别

在“设置与备份”中填写阿里云百炼 API Key、控制台提供的地域原生服务地址，以及控制台要求的业务空间标识。模型固定为 `qwen3.5-ocr`。密钥与地域必须匹配；部分业务空间需使用形如 `https://业务空间.cn-beijing.maas.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation` 的地址，请以自己的控制台为准。

API Key 由 Windows 当前用户加密，保存在数据目录旁的 `Settings/qwen.dpapi`，不进入库存备份。换电脑或 Windows 用户时需要重新配置。默认直连服务，不修改系统代理。识别按输入与输出 Token 计费，软件不推算或承诺单次费用。

## 照片进货

1. 在“进货”点击“照片识别进货”，选择、拖入 JPG/PNG，或摄像头拍照。
2. 程序在本机检测表格，橙色四边形仅作为候选。点击“调整四角”，依次点击左上、右上、右下、左下，然后“应用四角”做透视校正；也可点击“框选裁剪”，拖选后查看预览，再点击“应用裁剪”。取消预览会保留当前图片、核对明细和上传确认，可重新框选。应用后保留缩放比例，图片回到左上角，旧核对明细及上传确认清除。旋转后重新确认范围。
3. 截图须保留表头、全部货品行和分区合计，并排除客户资料、二维码、物流备注。对照截图后勾选允许上传。只有点击“识别确认的截图”才会上传。
4. 左侧约40%显示照片，右侧约60%显示结果。先检查每行货品。已有货品点“搜索已有货品”；选择后，如果资料不同，会显示差异。点击“使用这个货品的资料”填入，或“返回修改”。照片原文和已经填写的数量保留。如果是新货品，点“新建货品”，先保存零库存档案；取消进货草稿也会保留这个档案。
5. 修改绿色区域里的“本次进货数量”：点中间的数字直接输入，或者点－、＋。这里只能填整数，进货可填0。旁边的“辆／组／个／件”是库存单位，下面的“照片识别的数量”只供对照。最后入库以“本次进货数量”为准。
6. 如果单位没有识别出来或与所选货品不同，页面会显示单位确认说明。对照照片，必要时先手动把数量换算为库存单位，再勾选确认；软件不会自动换算。原单位与人工确认信息随照片和单据保存。
7. 每行检查完后，点击“已核对”，也可用键盘空格勾选。有问题时，软件会指出原因并跳到需要处理的字段；处理后再勾选。改了货品或数量，页面会提示“内容已修改，请重新核对”。顶部显示还有几行需要处理。
8. 如果当前数量合计与照片不同，先检查每行数量。确实是照片上的合计写错了，再展开“照片上的合计写错了？在这里填写原因”。确认单位不能代替合计说明。没有确认实发数量列时，保留表头重新识别，或关闭照片窗口返回手动填单。
9. 每行都核对后，点“加入进货清单”。可继续导入下一张照片；重复货品保留独立行。同一草稿不能重复加入相同截图，历史用过的照片会提示。
10. 在进货清单中检查数量，点击“查看确认页”，再点“确认入库”。只有这一步才增加仓库库存。在清单再次改照片行的数量后，需要重新勾选该行“已核对”。

主识别不会显示推测的坐标或置信度。默认用截图缩放对照。“在照片中查找（另行付费）”会经确认另发一次付费请求，同一图片会话内复用结果。只有完整文字唯一匹配才高亮；重复文字仅列出候选，不绑定某一行。

1.1.4升级包已内置并启用用户确认可用的识图EXE，继续使用主程序已有的百炼配置，在后台运行，不需要打开独立测试窗口或手动复制文件。原识别实现仍保留。鉴权、欠费、权限、限流、连接失败、超时和截断会分别提示，图片和已有草稿保留，没有自动重试。新后台连同启动最多等待120秒，云端请求上限90秒，可取消；迟到响应不会覆盖明细。断网可选择本机离线备用识别或手工录入；离线识别仍须检查数量列和所有字段。

识别返回部分字段不完整时，软件保留原行并显示待核对原因。缺失的说明、标识和分区合计可留空；数量缺失不会变为零，异常数量会保留原文，修正为有效整数后才能核对。类型不明时请选择货品类型，并选择资料完整的已有货品或新建货品。单位不一致时按页面说明人工确认。额外字段不参与数量或货品映射。实发列未确认时整张不能加入清单；重复字段、截断或无法解释的明细结构会拒绝，并指出具体位置。所有成功识别的行仍需人工核对。

实发列标志以文字形式返回时，明确的 `true/false` 可转换并显示兼容提示，支持大小写和首尾空白。缺失、空值及数字、其他文字、数组或对象均按“实发列尚未确认”处理，保留可用明细，但勾选核对或填写合计说明不能解除加入清单的限制。请包含列标题重新识别，或关闭照片核对窗口，返回进货清单手动录入；软件不根据数量或合计猜测实发列。

## 手工业务、调拨与作废

货品名称、规格和颜色可选择已有词条，也可直接填写新值。照片核对页和新增货品窗口都支持此功能：输入“飞驰”时自动显示“飞驰一代”“飞驰二代”等包含关键词的已有名称；点击候选项，或用上下键选择、Enter填入。未选择候选项时，输入的“飞驰”保持不变，可按原流程新建货品。颜色留空时点击字段或右侧下拉箭头，可选“薄荷绿”“天蓝”等已有颜色，也可保持空白。

词条来自本机现有货品资料，去重后显示最多50个；输入更多关键词缩小范围。选择词条只改变当前字段，不自动填充其他字段或创建货品；完整类型、名称、规格、颜色、编码仍按原规则匹配。电池、充电器颜色必须为空。Esc关闭候选，Tab保留输入并跳到下一个字段。物料编码、单位、类型、数量等其他字段保持原操作。

手工进货可直接点击“新建货品”，先确认零库存档案，再选中该货品并“添加到清单”；填写名称、规格、颜色时使用同一词条功能。只有最后确认入库才增加进货数量。

新增货品的期初库存单独记账，不计入厂家进货。厂家进货增加仓库库存；零售或批发出货只扣仓库，必须明确渠道。仓库不足时先“调整分布”，从店面调回仓库；调拨不改变合计。库存不允许负数。

库存、进出货选品可搜索名称、规格和编码，也可组合筛选；选品每页100种。进出货中的相同货品可以有多行，确认页按货品合计显示库存变化。

记录详情显示全部原行、照片序号、原序号、标识和字段快照。作废须填写原因，在当前日期生成反向流水；重复行按货品合计校验余额，不会重复扣减。不能作废已作废单据。

## 查询、汇总与导出

“组合筛选”支持类型、名称、规格、颜色多选，以及物料编码搜索。同一栏勾选多个值时，匹配其中一个即可；不同栏的条件需要同时满足。规格与颜色候选来自实际货品，可搜索和翻页。空颜色显示“无颜色”；旧资料的“颜色未记录”另选。

记录查询每页100张单据，只显示符合筛选的明细；打开单据详情仍保留完整原单。日期选项包括今日、昨日、过去7天、上个月、过去3个月、过去6个月、去年及自选。

“分类汇总”可组合名称、规格、颜色维度，类型与单位始终分开。库存显示仓库、店面和合计；进出货只计有效原单，作废原单与反向流水不会重复计入。双击汇总行查看分页明细。

库存与记录均可导出 Excel。选择明细列和汇总维度，货品资料字段默认勾选；可只导出汇总。导出覆盖全部结果，附筛选条件、维度、时间及保留起始日。大量数据按工作表上限分表，导出过程中窗口可响应、可取消；取消或失败不会覆盖既有目标文件。

## 三年保留与备份恢复

保留截止日为本机业务日期减三年，截止日当天保留。启动、跨日和恢复时先结转过期流水，核对“结转＋保留流水＝当前余额”，再清理过期单据与无引用照片。非零库存以及仍被保留单据引用的货品不删除；无库存、无引用且三年未使用的货品才会删除。旧货品使用时间不明时从迁移日保守计算。

时钟回拨不会重新开放已清理日期；照片删除失败记日志、下次重试。用户另存的备份与 Excel 不自动删除，备份可能仍包含三年前历史。

在设置中保存 `.stockbackup`，包含数据库和关联照片，不包含 API Key。恢复前先备份当前数据；恢复支持 v1/v2，先在暂存目录校验、迁移、核对并执行三年维护，成功后才替换当前数据。不能合并多个备份。卸载保留库存、照片、密钥设置和保护备份。
