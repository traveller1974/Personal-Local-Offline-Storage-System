# 本地库存管理 1.3.0

界面采用柔和蓝灰配色，主程序、业务弹窗和独立识图工具统一使用圆角按钮、清晰的操作状态和文字层级。

- 库存表格优先给规格和颜色分配空间。长名称、规格、颜色和编码自动换行，行高随内容增长，可以通过纵向滚动阅读完整内容。
- 货品名称、类型和单位更紧凑，调整分布与编辑按钮完整显示；空间不足时可横向滚动。数量通常使用紧凑宽度，位数较多时自动加宽，避免截断或拆行。
- 进出货清单、货品选择、汇总、确认页和单据详情同步改善长文本显示。保留数量输入、词条选择和原有业务步骤。
- 设置页面分为照片识别、核对记录和本机备份三块，关闭按钮保持在底部；窗口打开时适配当前显示器工作区。
- 识图页面仍采用约40%图片、60%结果布局。“已核对”继续作为可选标记，最终入库采用人工确认的清单数量。

关闭主程序后，运行 `LocalStockManager-1.3.0-win-x64-Setup.exe` 升级。升级保留库存、照片、词条、核对记录、识别服务选择和加密密钥。改版后的独立识图EXE已经嵌入主程序。

本次改版使用本地测试数据和响应回放验证界面，没有新增真实模型调用。模型准确率仍参考1.2.1的固定样单结果，尚未通过端到端自动填单验收。
