# 本地库存管理 1.1.1

本补丁修复裁剪后仍显示缩放原图的问题，并改善百炼识别返回字段不完整时的处理。

- 已复现图片缓存问题：实际文件裁剪为80×60像素后，界面仍显示缓存的200×120像素原图。改为读取最新图片内容，保持比例，预览与实际上传共用处理图。
- 框选后先显示裁剪预览，点击“应用裁剪”生效；取消保留当前图片与核对内容。支持反向拖动、缩放、滚动与越界截取，应用后重新确认上传范围。
- 缺少可选字段、分区合计和出现额外字段时，保留明细供核对。数量缺失不转成零，异常数量保留原文，类型不明保持“未知”。关键字段未修正不能核对，未确认实发列不能加入清单。
- 重复字段、JSON截断和不明明细结构继续拒绝，提示具体行和字段；失败与迟到响应保留已有核对明细，不自动重试。

安装与覆盖安装只更新程序目录。已有数据库、照片、加密密钥设置及备份继续保留；安装前关闭软件。现有三年历史维护规则继续执行，本补丁不修改数据库结构。

开发验证使用隔离数据和模拟接口，不读取用户API Key，不上传用户照片。真实云端验收仍待用户在软件内主动识别完成，不能把模拟测试当作真实样单准确率证明。

测试结果、安装包校验值和精简证据见[验收报告](验收报告.md)。
