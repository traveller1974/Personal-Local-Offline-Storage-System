# 本地库存管理 1.1.4

发布日期：2026-10-07。

本版修复照片进货的人工核对和数量操作，并简化主程序各页面的说明。

- “已核对”支持点击及键盘空格。条件不满足时，说明是哪一项有问题，并跳到需要处理的输入框；修改后可以重新核对。顶部显示核对进度，加入清单时列出尚未处理的行。
- 选择已有货品时显示资料差异，确认后填入类型、名称、规格、颜色和编码，保留照片识别原文和本次进货数量。直接手动填写完整资料也会查找匹配货品，不必选择某个词条才刷新。
- “本次进货数量”单独一行，可点数字输入或用－、＋修改。修复加减按钮破坏数据绑定的问题，输入框、清单、合计和最终库存使用相同数量。进货可填0，出货至少为1。
- 单位缺失或不一致时，可对照照片明确确认数量按库存单位计；保留原识别单位和人工说明，需要换算时手动修改数量。单位确认不能解除合计差异或实发列未确认的限制。
- 页面提示使用“新建货品”“选择已有货品”等日常用语，耗时和Token信息移到“技术详情”；上传、付费、作废和恢复备份的后果继续明确说明。

安装前关闭软件，再运行 `LocalStockManager-1.1.4-win-x64-Setup.exe`。升级包继续启用已验收的同一份识图EXE；模型调用、协议和数据库结构保持原样，已有数据与配置保留。
